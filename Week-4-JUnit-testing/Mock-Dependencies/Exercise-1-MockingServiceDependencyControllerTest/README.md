# Exercise 1 - Mocking a Service Dependency in a Controller Test

## Objective

Write a unit test for a Spring controller that uses a service to fetch data by mocking the service dependency with Mockito.

## Technologies

- Java 17
- Spring Boot
- Spring Web
- Spring Test
- Mockito
- JUnit 5

## Result

Successfully tested the `/users/{id}` endpoint using MockMvc with a mocked `UserService`.
