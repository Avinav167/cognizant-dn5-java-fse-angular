# Exercise 3 - Mocking a Service Dependency in an Integration Test

## Objective

Write an integration test for a Spring Boot application by mocking the service layer with Mockito.

## Technologies

- Java 17
- Spring Boot
- Spring Web
- MockMvc
- Mockito
- JUnit 5

## Result

Successfully tested the `/users/{id}` endpoint using `@SpringBootTest`, `@AutoConfigureMockMvc`, and a mocked `UserService`.
