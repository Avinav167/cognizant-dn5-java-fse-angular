# Exercise 4 - Arrange-Act-Assert (AAA) Pattern

## Objective

Learn the Arrange-Act-Assert (AAA) testing pattern and use JUnit setup and teardown methods.

## Concepts Covered

- Arrange
- Act
- Assert
- @Before
- @After

## Project Structure

```
Exercise-4-AAAPattern
│── pom.xml
│── README.md
└── src
    ├── main
    │   └── java
    │       └── com
    │           └── cognizant
    │               └── Calculator.java
    └── test
        └── java
            └── com
                └── cognizant
                    └── CalculatorTest.java
```

## Technologies Used

- Java
- Maven
- JUnit 4.13.2

## How to Run

Compile:

```bash
mvn clean compile
```

Run Tests:

```bash
mvn test
```

## Expected Output

```
Tests run: 1
Failures: 0
Errors: 0

BUILD SUCCESS
```
