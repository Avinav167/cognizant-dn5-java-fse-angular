# Exercise 3 - Assertions in JUnit

## Objective

To learn and use different JUnit assertions to validate test results.

## Scenario

Write JUnit test cases using various assertion methods such as:

- assertEquals()
- assertTrue()
- assertFalse()
- assertNull()
- assertNotNull()

## Project Structure

```
Exercise-3-AssertionsInJUnit
│── pom.xml
│── README.md
└── src
    ├── main
    │   └── java
    └── test
        └── java
            └── com
                └── cognizant
                    └── AssertionsTest.java
```

## Assertions Used

- `assertEquals()`
- `assertTrue()`
- `assertFalse()`
- `assertNull()`
- `assertNotNull()`

## Technologies Used

- Java 23
- Maven
- JUnit 4.13.2
- VS Code

## How to Run

Compile the project:

```bash
mvn clean compile
```

Run the JUnit tests:

```bash
mvn test
```
