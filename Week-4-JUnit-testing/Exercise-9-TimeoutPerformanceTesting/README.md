# Exercise 9 – Timeout and Performance Testing

## Objective

Verify that a method completes within a specified timeout using JUnit 5.

## Technologies Used

- Java 23
- Maven
- JUnit 5

## Files

- PerformanceTester.java
- PerformanceTesterTest.java

## Features

- Uses `assertTimeout()`
- Tests execution time
- Validates performance constraints

## Maven Commands

Compile:

```bash
mvn clean compile
```

Run Tests:

```bash
mvn clean test
```

## Expected Output

```
BUILD SUCCESS
```

## Learning Outcome

Understand how to verify execution time and timeout conditions using JUnit 5.
