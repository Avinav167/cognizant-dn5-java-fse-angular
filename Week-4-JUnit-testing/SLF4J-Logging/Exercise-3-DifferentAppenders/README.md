# Exercise 3 - Using Different Appenders

## Objective

Demonstrate logging using multiple appenders with SLF4J and Logback.

## Technologies

- Java 17
- Maven
- SLF4J
- Logback

## Appenders

- ConsoleAppender
- FileAppender (`app.log`)

## Output

Logs are displayed on the console and also written to the `app.log` file.

## Run

```bash
mvn compile
```
