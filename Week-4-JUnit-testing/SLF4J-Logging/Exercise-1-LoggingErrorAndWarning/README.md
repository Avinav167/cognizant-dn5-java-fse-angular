# Exercise 1 - Logging Error Messages and Warning Levels

## Objective

Demonstrate logging error and warning messages using SLF4J with Logback.

## Technologies Used

- Java 17
- Maven
- SLF4J API
- Logback

## Output

The application logs:

- An ERROR message
- A WARNING message

## Run

mvn compile

java -cp target/classes;target/dependency/* com.cognizant.LoggingExample
