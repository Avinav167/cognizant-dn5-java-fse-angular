# Exercise 7 - Financial Forecasting

## Objective

Predict future financial values using recursion.

## Classes

- FinancialForecast
- ForecastTest

## Algorithm

Recursive forecasting based on annual compound growth.

## Time Complexity

- Time: O(n)
- Space: O(n)

## Optimization

An iterative solution performs the same computation with O(1) auxiliary space.

## Output

Calculates and displays the predicted future value after the specified number of years.
