# Exercise 1 - Inventory Management System

## Objective

Develop an Inventory Management System using HashMap to efficiently manage products.

## Classes

- Product
- InventoryManager
- InventoryTest

## Data Structure Used

HashMap<Integer, Product>

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Add | O(1) |
| Update | O(1) |
| Delete | O(1) |
| Search | O(1) |

## Output

The program demonstrates adding, updating, deleting, and displaying products in the inventory.
